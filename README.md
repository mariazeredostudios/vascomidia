# Vasco International

Repositório de continuidade do projeto **Vasco da Gama International** — gestão
de redes sociais (@vasco_international) e produção de conteúdo para a
**Seletiva Vasco International** (16/08/2026) e a Disney Cup 2027.

Este repositório substitui a pasta local `Claude Vasco International` como
fonte de memória do projeto entre sessões.

- **[`CLAUDE.md`](./CLAUDE.md)** — leia primeiro. Memória completa do projeto:
  fatos oficiais, identidade visual, regras de engajamento, pipeline de
  geração de reels, erros já corrigidos e pendências abertas.
- **`docs/`** — documentação de referência (resumo do projeto, direcional
  visual oficial, estratégia de conteúdo da reta final da seletiva).
- **`content/reels/`** — vídeos produzidos, com a data no nome do arquivo.
- **`scripts/`** — (a trazer) pipeline Python/ffmpeg de geração dos reels
  faceless, ainda não migrado da pasta local para este repositório.
